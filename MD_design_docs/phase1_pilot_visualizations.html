CLAMP Phase 1 pilot — dataset visualizations

6,776-row stratified sample of a 90,697-row pull across five AMP/hemolysis sources (DBAASP, DRAMP, Hemolytik2, HemoPI2, QMAP), pulled 2026-07-22 for PeptideCLM-2 transfer-learning work. Sampling kept all HC50-labeled rows and capped MIC-only / unlabeled rows per source — so raw counts below are not proportional to the full pull (see callout).

6,776 rows
Reading this page: every color that encodes a source (DBAASP / DRAMP / Hemolytik2 / HemoPI2 / QMAP) is fixed across every chart on this page — same hue, same source, everywhere. Every chart below has hover/focus tooltips and a "View as table" twin for the exact numbers. Charts compare this sample, not the full 90,697-row pull — the full-pull source shares (§1 of the companion report) are roughly DBAASP 1.2% / DRAMP 12.9% / Hemolytik2 7.1% / HemoPI2 2.1% / QMAP 76.7%, quite different from the sample's mix below because HC50 rows (rare in the full pull) were deliberately over-sampled.
Composition

What's in the sample, and who actually has labels

Row counts reflect the sampling strategy, not the underlying corpus (caveat above). The more informative view is at the peptide level: because dedup merges cross-source records sharing a peptide_uid, a peptide can carry a label it didn't itself measure — DRAMP and Hemolytik2 contribute zero raw MIC values, yet a share of their peptides show ≥1 MIC value borrowed from a co-occurring DBAASP/QMAP record.

Cross-source identity

How much do sources overlap on the same peptide?

527 of 5,515 unique peptides in this sample (9.6%) appear under more than one source. QMAP — itself largely DBAASP-derived — overlaps with everything; the DBAASP↔QMAP link is comparatively small here because this pilot only pulled ~150 real DBAASP peptides (full-scale DBAASP will raise it).
